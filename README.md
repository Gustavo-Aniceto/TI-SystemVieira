VieiraStock

Sistema de Estoque TI - Gerenciamento completo de inventário de tecnologia da informação.

## Funcionalidades

- Gestão de produtos e categorias
- Controle de estoque com alertas
- Sistema de chamados técnicos
- Calendário de eventos
- Gerenciador de senhas
- Anotações e listas de tarefas
- Relatórios em Excel
- Controle de usuários e permissões

## Tecnologias

- React + TypeScript
- Tailwind CSS
- Vite
- Lucide React (ícones)

## Como usar

1. Instalar dependências: `npm install`
2. Executar em desenvolvimento: `npm run dev`
3. Build para produção: `npm run build`
